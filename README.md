# Applied Artificial Intelligence Labs

Laboratory work completed for the **Applied Artificial Intelligence** course
at ITMO University.

## Repository Structure

| Lab | Topic | Main approaches | Result |
| --- | --- | --- | --- |
| [LAB1](LAB1/) | Human activity recognition from mobile sensor data | KNN, Decision Tree, SVM | Best accuracy: **97%** with SVM |
| [LAB2](LAB2/) | House price prediction | Feed-forward neural networks | Best RMSE: **46,022** |
| [LAB3](LAB3/) | Flower image classification | CNN, transfer learning, ResNet50 | Validation accuracy: **88.6%** |

## Skills and Technologies

- Python, Pandas, NumPy and Matplotlib
- Scikit-learn, TensorFlow and PyTorch
- Data preprocessing and exploratory analysis
- Classification and regression
- Neural networks and convolutional neural networks
- Transfer learning and hyperparameter tuning
- Model evaluation with accuracy, precision, recall, F1-score and RMSE
